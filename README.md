# Ooru (ಊರು)

Neighbourhood intelligence platform. WhatsApp-first food delivery, local commerce and community mesh. Live at **https://ooru.ai**

Created by **Sagar.U**

## What it does
- WhatsApp-first ordering — no app needed
- Food delivery as neighbourhood sensor mesh
- Local shop discovery + dual listing
- Claude AI conversational brain (7 personas, 73 intents)
- Neighbourhood page — Pill + Map + Claude Box
- Champion teams open to all (Law 13)
- Satellite data three-tier (Sentinel/MODIS → Maxar → Planet)

## Stack
React 18 · TypeScript · Tailwind v4 · Zustand · Leaflet · Express 5 · Drizzle ORM · PostgreSQL · Gupshup WhatsApp BSP · nginx · Hetzner

## Standards
WhatsApp Business API · H3 Hex Grid · NDVI/NDWI/EVI Satellite Indices
